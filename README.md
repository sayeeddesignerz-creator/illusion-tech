# Illusion Tech

A minimal, dependency-free hello world page.

## Preview

Open `index.html` in any browser — no build step or server required.

## Structure

```
.
└── index.html   # Single-file page (HTML + CSS + tiny JS)
```

## Deploying

The page is fully static, so it works anywhere:

- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Any static host:** upload `index.html` as-is.
